## 5. 完整范例：新增一个壳设置项（端到端模板）
以"背景图片"为实例（已落地），新增任何类似能力按此四步 + 一步文档：

**① admin 路由（`src/admin.mjs`，纯 Node 可单测）**
```js
// 背景图片供给：Chromium 禁 http 页面加载 file://，本地图必须走回环 HTTP
if (req.method === 'GET' && u.pathname === '/bg-image') {
  const p = String((readSettings() || {}).backgroundImage || '')
  if (!p || !fs.existsSync(p)) return json(res, 404, { ok: false, error: 'no background image' })
  const data = fs.readFileSync(p)
  const mime = MIME_BY_EXT[path.extname(p).toLowerCase()] || 'application/octet-stream'
  res.writeHead(200, { 'Content-Type': mime, 'Content-Length': data.length, 'Cache-Control': 'no-store' })
  return res.end(data)
}
```

**② 主进程 action + 状态（`src/main.mjs`）**
```js
const BG_ALLOWED_EXT = ['.jpg', '.jpeg', '.png', '.webp', '.gif', '.bmp', '.avif', '.ico']
function setBackgroundImage(filePath) {
  if (filePath) {
    if (!fs.existsSync(filePath)) return { ok: false, error: '文件不存在' }
    if (!BG_ALLOWED_EXT.includes(path.extname(filePath).toLowerCase())) {
      return { ok: false, error: '不支持的图片格式，请使用 jpg/jpeg/png/webp 等' }
    }
    readSettingsWriteBackground(filePath)   // 持久化 settings.json
    applyBackgroundCss()                     // 注入/更新窗口 CSS
    return { ok: true, path: filePath }
  }
  clearBackground(); return { ok: true, cleared: true }
}
// 装配：createAdminServer({ ..., actions: { ..., setBackground: setBackgroundImage, pickBackground: pickBackgroundImage, quit: (code) => cleanup(code) } })
// 暴露：statusPayload() 增加 backgroundImage 字段（客户端 UI 依赖）
```

**③ 客户端设置行（`packages/dsh-desktop-ui/lib/client.js`）**

### 范例二：客户端按钮交互样式（ghost + hover/active，0.4.5 落地）

```js
// ① 行内基底：ghost 透明 + 边框（hover 高亮交给注入样式表）
const css = { button: { cursor: "pointer", background: "transparent", border, borderRadius: "8px", padding: "6px 12px" } }
// ② 按钮统一带 className
react.createElement("button", { style: css.button, className: "dsh-desktop-btn", onClick: ... }, "应用")
// ③ apply() 注入样式（ctx.effect 回收；hover 必须 !important 压行内样式）
const styleEl = document.createElement("style")
styleEl.textContent = `
  .dsh-desktop-btn { transition: background-color 0.15s ease, border-color 0.15s ease; }
  .dsh-desktop-btn:hover { background: var(--dsw-alias-interactive-bg-hover) !important; }
  .dsh-desktop-btn:active { background: var(--dsw-alias-interactive-bg-active) !important; }
  .dsh-desktop-btn:focus-visible { outline: 1px solid var(--dsw-alias-brand-primary, #3964fe); outline-offset: 1px; }
`
document.head.appendChild(styleEl)
ctx.effect(() => () => styleEl.remove(), "dsh-desktop-ui: button styles")
// ④ 验证：CDP 鼠标移动实测 rest→hover 背景变化（见坑 15；探针脚本已于 2026-09-13 清理）
```
